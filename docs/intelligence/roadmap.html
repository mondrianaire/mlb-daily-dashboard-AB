Deliberately not

LLM / serverless backend
Removed by choice. The product is purely static and self-updates from the MLB API on load. Revisitable as a build-time JSON precompute if ever wanted.
GAP-001 · wontfix
Predictive win / playoff odds
A made-up number on a stats product erodes trust; no owned data to back a real model.
RISK-002 · guardrail
Real push notifications
Needs a backend/push service — against the static stance. Local-only alerts are too weak to bother.
