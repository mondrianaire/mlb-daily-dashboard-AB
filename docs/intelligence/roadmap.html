Next · bigger bets

Game box-score detail
Click any game → line score by inning (R/H/E), team lines, scoring plays. Deepens the live experience.
Impact High~1 day
Player leaders
A League Leaders surface (HR, AVG, ERA, K, SB) — adds the player layer the team-only dashboard lacks.
Impact Med-High~½–1 day
Module cache-busting (hardening)
Engine modules import by plain path, so a returning visitor can pair a fresh app.js with a stale cached module and break. Version-stamp the imports (or precache them in the SW) to close the gap.
Impact Med · correctness~½ day
Accessibility pass
Mobile Trends overflow is fixed (v1.17). Remaining: keyboard nav, ARIA, contrast/touch-target audit. Quality + reach.
Impact Med~½ day
PNG app icons
Add 192/512 PNGs for maximum install fidelity on older Android (SVG icon already ships).
Impact Low~1 hr

Deliberately not

LLM / serverless backend
Removed by choice. The product is purely static and self-updates from the MLB API on load. Revisitable as a build-time JSON precompute if ever wanted.
GAP-001 · wontfix
Predictive win / playoff odds
A made-up number on a stats product erodes trust; no owned data to back a real model.
RISK-002 · guardrail
Real push notifications
Needs a backend/push service — against the static stance. Local-only alerts are too weak to bother.

Honest read: nothing here is overdue.
